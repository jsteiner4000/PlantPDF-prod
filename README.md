# PlantPDF

PDF-Editor für Windows: Texte und Bilder in PDF-Dateien bearbeiten, Seiten einfügen, löschen
und ordnen, Dokumente unterschreiben – und im Bereich „Dokumentation“ Kundendokumentationen,
Bedienungsanleitungen und Technische Beschreibungen als PDF erstellen. Alles bleibt auf dem
eigenen Rechner.

## Download

**[Neueste Version herunterladen](https://github.com/jsteiner4000/PlantPDF-Prod/releases/latest)**
(Datei `PlantPDF-Setup-x.y.z.exe`) · [Alle Versionen](https://github.com/jsteiner4000/PlantPDF-Prod/releases)
· [Website](https://jsteiner4000.github.io/PlantPDF-Prod/)

Windows 10/11. Installer ausführen – installiert wird nur für den eigenen Benutzer,
Administratorrechte sind nicht nötig. Eine neue Version installiert man genauso über die alte;
Einstellungen und Daten bleiben erhalten.

## Updates

PlantPDF sucht beim Start (höchstens einmal am Tag) hier nach einer neuen Version und bietet sie
zur Installation an – auch über „Hilfe › Nach Updates suchen …“. Übertragen wird nur die Anfrage
nach der neuesten Versionsnummer und ggf. der Download des Setups, keine Dokumente oder Nutzerdaten.

Versionen **vor 2.35.1** suchen noch an der alten Adresse und finden neue Updates nicht mehr von
selbst. Dann den Installer einmal von Hand laden und ausführen; ab dann läuft es wieder automatisch.
